# Studio · studio.stepx.com 手机客户端

把 `studio.stepx.com` 封装成独立 Android App，绕开手机浏览器对上传、下载、长按、全屏、第三方登录的限制。

## 为什么用它

手机浏览器里常见的坑：文件上传只能从「文件」里挑、下载的文件找不到、长按图片没反应、视频不能全屏、切到别的 App 回来就被刷新。这个客户端逐条处理：

- **登录保持**：Cookie / 本地存储持久化，退出再进不用重新登录
- **文件上传**：原生文件选择器 + 拍照直接传（图片 / 文档都支持）
- **文件下载**：走系统下载器，完成后通知栏可见，文件落在「下载」目录
- **长按存图**：长按任意图片可直接保存或复制链接
- **视频全屏**：网页里的视频可以真正全屏播放
- **外链处理**：电话、邮件、微信等链接自动唤起对应 App，网页链接继续在 App 内打开
- **断网兜底**：加载失败时给重试页，不用杀掉重进

## 安装

1. 手机打开下载页：https://github.com/zachshi-ai/studio-app
2. 下载 `Studio-v1.0.apk`
3. 允许「安装未知来源应用」后完成安装
4. 首次打开会直接加载 studio.stepx.com，正常登录一次即可长期保持
